Your job search, on your own computer.

Aarka Tech finds roles worldwide, shows how well you fit each one, tailors your resume and cover letter, and tracks every application and follow-up. Your resume and records stay on your machine.

Everything from search to follow-up

Searching and tracking are free and need no AI. For evaluations and tailored documents, connect an AI tool you already use.

Discover

Global job search

Scans public company career pages. Filter by country, city, work mode, seniority and freshness, and favourite the companies you care about.

Decide

Fit you can see

Each evaluated job shows a score, a verdict, requirements you match or miss, and what to do next. Nothing is invented.

Apply

Tailored documents

Resumes and cover letters built from your verified profile, checked against your source resume before you use them.

Track

Applications and follow-ups

A stage board for every role, "Mark already applied", reminders when it's time to follow up.

Add

Any job link

Paste a link from anywhere. Sign-in pages are never bypassed; paste the description instead.

Profile

Career Hub

Upload your resume, review what was read, fill gaps from a checklist, and see an evidence-based SWOT of your profile.

Private by design

  • Runs on your computer. There is no Aarka Tech server or account, and no tracking.
  • Your resume, profile and tracker are plain files you own.
  • API keys go to your macOS Keychain. An optional encrypted vault holds ID and salary documents and never sends them anywhere.
  • Nothing is ever sent, submitted or posted for you. Gmail support only creates drafts.
  • AI is optional, uses the provider you choose, and is never switched on without your confirmation.

Install

Needs Node.js 22.6+ and Git. macOS is the main platform for this alpha; the web app and job search also run on Linux and Windows.

git clone https://github.com/Yogendra1303/aarka-tech.git
cd aarka-tech
npm install
npm --prefix web ci
npm --prefix web run build
npm --prefix web start      # open http://127.0.0.1:3000

This page is a project overview. The app itself runs on your own machine, where your data lives; there is no hosted version.
