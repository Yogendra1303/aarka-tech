# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers, and keep discussion about the work.
Harassment, personal attacks and sharing other people's private information are not tolerated.

Report unacceptable behaviour privately to the maintainers through the contact listed on the
repository's GitHub profile, or by opening a private security advisory if no other channel is
available. Reports are handled confidentially.
