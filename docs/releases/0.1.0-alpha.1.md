# Aarka Tech 0.1.0-alpha.1 (pre-release)

First public alpha. Based on career-ops 1.37.0 plus upstream main as of 2026-10-20 (MIT).

## Highlights
- Redesigned local web app: My Career Hub, Dashboard, Explore Jobs, Applications board, Follow-ups,
  Documents, Automation, Job Sources, Analytics, Integrations & Settings. Light and dark themes.
- Global job search with country → city picker, work mode, seniority, employment type, job board and
  freshness filters; 24 results per page with Load more; save, dismiss and favourite companies (persisted).
- Applications board by stage with each role's fit score, verdict, strengths and gaps from its evaluation.
- Bring-your-own AI: CLI tools you are signed in to, or API keys stored in the macOS Keychain; explicit
  billing confirmation, no silent fallback.
- Personal records vault (macOS): AES-256-GCM, key in Keychain, never sent to AI or added to packs.
- Optional background automation for macOS (launchd), AI stage off by default.
- Gmail drafts only (`gmail.compose`), using your own Google OAuth client.

## Fixed during release preparation
- Applications no longer shows an outdated loading layout; load failures show an error with Try again.
- First tracker merge on a fresh install creates the tracker instead of finding nothing to merge into.
- Cloudflare provider reports "Needs account ID" instead of a generic error.
- Removed machine-specific paths and names from code and tests; automation now lives in `automation/`.
- AI-engine tests no longer depend on the working directory.

## Known limitations
See [KNOWN_LIMITATIONS.md](../KNOWN_LIMITATIONS.md). In short: macOS-first, salary/visa/time-zone data
is rarely available from job boards, AI quality and cost depend on your provider, alpha stability.

## Upgrade notes
New install only. Your data files are git-ignored and stay where they are.
